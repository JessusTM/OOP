## Strings

En esta sección se introducen las cadenas de texto en Java mediante el tipo `String`. Dado que `String` es un *tipo de referencia*, se utiliza para representar texto y trabajar con operaciones comunes como concatenación, validaciones y transformaciones.

## Contenido

- *Introducción*: qué es `String`, por qué es tipo de referencia y cómo se crea.
- *Concatenación*: distintas formas de unir texto y consideraciones prácticas.
- *Inmutabilidad*: qué significa que `String` sea inmutable y qué implica al modificar texto.
- *Validar*: diferencias entre `null`, vacío y blanco, y validaciones típicas.
- *Métodos*: métodos más usados para trabajar con texto en Java.
